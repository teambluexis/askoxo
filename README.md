# AskOXO

**Ask Anything. Explore Everything.**

AskOXO is a family-safe, pluralistic wisdom exploration platform built around a simple principle:

**One Question. Many Perspectives. Your Understanding.**

This repository currently contains the V0.5 interactive front-end demo.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Current demo

- Mobile-first AskOXO homepage
- Ask bar
- Exploration categories
- Trending questions
- Multi-perspective question experience
- AskOXO principles: pluralism, evidence and family safety

The functional MVP will add the structured knowledge layer, sources, AI retrieval, persistent conversations and editorial studio.
